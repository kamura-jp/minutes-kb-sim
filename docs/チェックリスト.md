# 登録前チェックリスト

- [ ] 原資料を最後まで読んだ
- [ ] 発言者は原資料に書かれている人物か（不明な発言は登録していない）
- [ ] 日付は YYYY-MM-DD で、原資料の日付と合っている（和暦は西暦に直した）
- [ ] 出典（ファイル名）が `data/raw/` に実在する
- [ ] 同じ内容を二重に登録していない
- [ ] 議事録どうしで食い違う内容は、最新の確認済みのものだけを登録した
- [ ] AIが補った事実が混ざっていない（原資料と照合した）
- [ ] 機密区分を付けた
- [ ] `python tools/validate.py` がエラー0件
- [ ] `git diff` で意図しない変更がない
- [ ] PRに「変更内容」と「確認方法」を書いた
