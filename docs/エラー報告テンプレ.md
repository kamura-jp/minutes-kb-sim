# エラー報告テンプレ

エンジニアや業務担当者に連携するときは、次の4項目を必ず書きます。

```
■ 対象ファイル：
■ 実行した操作（コマンド・手順）：
■ エラーメッセージ（そのままコピー）：
■ 自分で試したこと：
■ （あれば）影響範囲・急ぎ度：
```

## 記入例
```
■ 対象ファイル：data/kb/legal.yaml（KB-0004）
■ 実行した操作：python tools/validate.py
■ エラーメッセージ：[ERROR] legal.yaml KB-0004: source が未入力です
■ 自分で試したこと：原資料 minutes_2026-10-19_legal.txt を確認したが、該当の発言が複数あり、どれを出典にすべきか判断できなかった
■ 影響範囲：KB-0004のみ。ほかは検証を通過
```
